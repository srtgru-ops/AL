# نظام إدارة العمل التطوعي - جامعة تبوك

ملفات الموقع الجاهزة للرفع على GitHub Pages.

## الملفات
- `index.html` واجهة النظام.
- `university-tabuk-logo.png` شعار الجامعة المستخدم في الواجهة.

## دورة الطلب
قيد المراجعة → مقبول → بانتظار متطلبات الإنهاء → منتهية.

عند القبول يتم إرسال رابط التسجيل، وعند الضغط على **إرسال ملف الإنهاء** يتم استدعاء Apps Script لإرسال ملف Word، ثم يظهر زر **اعتماد الإنهاء** بعد استلام المتطلبات.
